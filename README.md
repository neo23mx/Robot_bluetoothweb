# Robot_bluetoothweb
proyecto de un robot de dos ruedas el cual puedes controlar con la app bluetooth electronics y por un servidor web, utiliza dos driver para controlar cada rueda independientemente y tiene un buzzer para tocar una nota y musica.

Tambien el control se hizo por un servidor web en el cual puedes controlar el robot, tambien se incluye una pagina web para que puedas aprender conceptos

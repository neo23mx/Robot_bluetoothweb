1. Variables y tipos de datos

¿Qué es una variable?

Una variable es un nombre que guarda un valor. En Python no necesitas declarar el tipo.

Ejemplo sencillo

nombre = "Ana"
edad = 12
altura = 1.55
es_estudiante = True

print(nombre)
print(edad)
print(altura)
print(es_estudiante)

Tipos de datos más comunes

  • str → texto (cadenas)
  • int → números enteros
  • float → números con decimales
  • bool → True o False

🎯 Reto

Crea tres variables:

  • Tu nombre (texto)
  • Tu edad (número entero)
  • Si te gusta programar (True o False)

Luego usa print() para mostrarlas todas.

Pista: recuerda poner comillas en el texto.

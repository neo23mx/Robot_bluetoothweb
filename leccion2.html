🤖 Lección 2: ¡El robot aprende a calcular!

Operadores y expresiones en Python para robótica y automatización

🚀 ¿Cómo puede calcular un robot?

En la lección anterior aprendimos que las variables permiten guardar información.

Pero un robot y un sistema automático necesitan hacer algo más: calcular.

Por ejemplo:

  • Calcular la velocidad de un motor.
  • Calcular una distancia.
  • Sumar lecturas de sensores.
  • Calcular cuánto tiempo ha funcionado un sistema.
  • Comparar valores para tomar decisiones.

Para hacer estos cálculos utilizamos operadores.

➕ 1. Operaciones matemáticas

Python puede realizar las mismas operaciones matemáticas que utilizamos normalmente. 

distancia = 20
avance = 15

total = distancia + avance

print(total)

El resultado será: 

35

El operador + sirve para sumar.

También tenemos: 

+   suma
-   resta
*   multiplicación
/   división

🤖 2. Calcular el movimiento de un robot

Imagina que nuestro robot avanza primero 30 centímetros y después otros 20 centímetros. 

avance1 = 30
avance2 = 20

distancia_total = avance1 + avance2

print(distancia_total)

Resultado: 

50

El robot ha recorrido un total de 50 centímetros.

Esto parece sencillo, pero la misma idea puede utilizarse para realizar cálculos mucho más complejos en un robot.

⚙️ 3. Calcular velocidades

Supongamos que queremos calcular una nueva velocidad para los motores. 

velocidad = 50

nueva_velocidad = velocidad + 20

print(nueva_velocidad)

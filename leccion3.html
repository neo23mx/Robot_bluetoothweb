🤖 Lección 3: ¡Ahora el robot puede decidir!

Condicionales en Python para robótica y automatización

🚀 De un programa que obedece a un programa que piensa

Hasta ahora hemos aprendido a guardar información y trabajar con datos. Pero un robot necesita hacer algo más: tomar decisiones.

Imagina un robot de cuatro ruedas avanzando por un camino. De repente, encuentra un obstáculo.

El robot necesita preguntarse:

¿Hay un obstáculo?

Si la respuesta es sí, debe detenerse. Si la respuesta es no, puede continuar avanzando.

Esa es precisamente la función de los condicionales en Python.

🧠 1. La decisión más importante: if

La palabra if significa "si".

Podemos decirle a Python:

"Si ocurre esto, haz esto otro."

Observa este ejemplo de un robot: 

distancia = 15

if distancia < 20:
    print("¡Obstáculo detectado!")
    print("Detener motores")

El sensor nos dice que el obstáculo está a 15 centímetros.

Python compara: 

15 < 20

Como la condición es verdadera, el robot recibe la instrucción: 

¡Obstáculo detectado!
Detener motores

🎯 Acabas de programar una decisión de un robot.

⚙️ 2. if + else: ¿avanzar o detenerse?

Ahora podemos darle al robot dos posibilidades. 

distancia = 50

if distancia < 20:
    print("Obstáculo detectado")
    print("Detener motores")
else:
    print("Camino libre")
    print("Avanzar")

Si la distancia es menor de 20 cm, el robot se detiene.

Si no, el robot puede avanzar.

Esto se puede representar así: 

             SENSOR
                ↓
        ¿Obstáculo cerca?
           ↙          ↘
         SÍ            NO
         ↓              ↓
     DETENER          AVANZAR

🤖 3. Un robot de cuatro ruedas toma decisiones

Ahora vamos a llevarlo un poco más lejos.

Supongamos que nuestro robot tiene cuatro ruedas y queremos que pueda avanzar o detenerse dependiendo de lo que detecte su sensor. 

distancia = 30

if distancia < 20:
    print("Obstáculo detectado")
    print("Motor izquierdo: DETENER")
    print("Motor derecho: DETENER")

else:
    print("Camino libre")
    print("Motor izquierdo: AVANZAR")
    print("Motor derecho: AVANZAR")

Observa algo importante:

Python no está controlando directamente las ruedas en este ejemplo. Primero estamos aprendiendo la lógica de decisión.

Más adelante podremos sustituir esos mensajes por instrucciones reales para motores.

🔧 Primero aprendemos a pensar el comportamiento. Después conectamos el comportamiento con el hardware.

🌱 4. La misma idea en un invernadero

Los condicionales no solamente sirven para robots. También son fundamentales en la automatización.

Imagina un invernadero con un sensor de temperatura. 

temperatura = 32

if temperatura > 30:
    print("Temperatura alta")
    print("Encender ventilación")

else:
    print("Temperatura adecuada")
    print("Mantener ventilación apagada")

El sensor proporciona un dato.

Python analiza ese dato.

Y finalmente se toma una decisión.

Sensor → Python → Actuador

Esta estructura aparece constantemente en los sistemas de automatización.

💧 5. Automatizando el riego

Ahora imaginemos un sensor que mide la humedad del suelo. 

humedad = 35

if humedad < 40:
    print("Suelo seco")
    print("Encender bomba de agua")

else:
    print("Humedad adecuada")
    print("Apagar bomba de agua")

Aquí aparece una de las ideas más importantes de la automatización:

El sistema puede reaccionar automáticamente a su entorno.

Nadie necesita estar presionando un botón constantemente.

🏠 6. También podemos automatizar una casa

Pensemos ahora en un sistema de domótica.

Tenemos un sensor de movimiento y una lámpara. 

movimiento = True

if movimiento:
    print("Movimiento detectado")
    print("Encender lámpara")

else:
    print("No hay movimiento")
    print("Apagar lámpara")

El mismo concepto que utilizamos para el robot ahora controla una parte de una casa.

🤖 Robot, 🌱 invernadero y 🏠 domótica pueden utilizar exactamente la misma lógica de programación.

🔀 7. ¿Y si existen varias posibilidades?

A veces no tenemos solamente dos opciones.

Por ejemplo, un robot puede encontrarse con diferentes situaciones. 

distancia = 35

if distancia < 15:
    print("Obstáculo muy cerca")
    print("Detener robot")

elif distancia < 40:
    print("Obstáculo detectado")
    print("Reducir velocidad")

else:
    print("Camino libre")
    print("Avanzar normalmente")

Aquí aparece una nueva palabra: elif.

elif permite comprobar otra condición cuando la anterior no se cumplió.

🧩 8. Tres decisiones para un robot

Ahora nuestro robot puede tener tres comportamientos diferentes:

  • 🛑 Detenerse.
  • 🐢 Reducir velocidad.
  • 🚀 Avanzar.

Podemos programarlo así: 

distancia = 35

if distancia < 15:
    print("DETENER ROBOT")

elif distancia < 40:
    print("REDUCIR VELOCIDAD")

else:
    print("AVANZAR")

Cambia el valor de distancia y observa cómo cambia el comportamiento del robot.

Imagina un invernadero inteligente.

El sensor proporciona la temperatura: 

temperatura = 32

Programa el sistema para que:

  • Si la temperatura es mayor o igual a 35 °C → encender ventiladores.

  • Si está entre 25 °C y 34 °C → mantener condiciones normales.

Un sensor proporciona información → Python decide → un actuador realiza una acción.

🤖 Lección 4: ¡El robot no se cansa!

Bucles en Python para robótica y automatización

🚀 ¿Y si el robot tiene que repetir una tarea?

En la lección anterior aprendimos a hacer que nuestro robot tome decisiones.

Pero imagina que nuestro robot está avanzando por un terreno. No queremos escribir: 

avanzar()
avanzar()
avanzar()
avanzar()
avanzar()

¿Y si queremos que avance durante cientos o miles de ciclos?

Necesitamos que Python pueda repetir instrucciones automáticamente.

Para eso existen los bucles.

🔄 1. El bucle while

while significa "mientras".

Podemos decirle a Python:

"Mientras esta condición sea verdadera, continúa haciendo esto." 

contador = 0

while contador < 5:
    print("Robot avanzando")
    contador = contador + 1

El programa repetirá la instrucción mientras contador sea menor que 5.

El resultado será: 

Robot avanzando
Robot avanzando
Robot avanzando
Robot avanzando
Robot avanzando

🤖 2. Un robot que revisa constantemente su entorno

En robótica, los sensores normalmente deben revisarse constantemente.

Podemos imaginarlo así: 

while True:

    leer_sensor()

    tomar_decision()

    mover_robot()

El robot hace algo parecido a esto una y otra vez:

  1. 👀 Lee sus sensores.
  2. 🧠 Analiza la información.
  3. ⚙️ Ejecuta una acción.
  4. 🔄 Vuelve a revisar.

Esta idea es fundamental en los robots autónomos.

🛑 3. while + if: el robot detecta obstáculos

Ahora vamos a combinar lo aprendido en la Lección 3 con los bucles. 

distancia = 50

while distancia > 0:

    if distancia < 20:
        print("¡Obstáculo!")
        print("Detener robot")
    else:
        print("Camino libre")
        print("Avanzar")

    distancia = distancia - 10

Aquí tenemos dos conceptos trabajando juntos:

while → repetir.

if → decidir.

Esta combinación es extremadamente importante en robótica.

🧠 4. El ciclo de un robot autónomo

Un robot autónomo puede trabajar siguiendo continuamente este ciclo: 

        ┌──────────────┐
        │ Leer sensores│
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │   Decidir    │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │    Actuar    │
        └──────┬───────┘
               ↓
             REPETIR
               ↑
               └────────

Esto se conoce como un ciclo de control.

Muchos robots y sistemas automáticos funcionan siguiendo precisamente este principio.

🌱 5. Un invernadero que trabaja solo

Ahora llevemos el mismo concepto a un invernadero.

Imaginemos que tenemos un sensor de temperatura. 

temperatura = 32

while True:

    if temperatura > 30:
        print("Temperatura alta")
        print("Encender ventilador")
    else:
        print("Temperatura adecuada")
        print("Apagar ventilador")

El sistema puede revisar continuamente la temperatura y decidir qué hacer.

En un sistema real, el valor de temperatura cambiaría porque vendría directamente de un sensor.

💧 6. Riego automático

Podemos hacer exactamente lo mismo con la humedad del suelo. 

humedad = 35

while True:

    if humedad < 40:
        print("Suelo seco")
        print("Encender bomba")
    else:
        print("Humedad adecuada")
        print("Apagar bomba")

El programa no necesita que una persona esté revisando constantemente el suelo.

El sistema puede hacerlo automáticamente.

🏠 7. Domótica: una casa que responde

Los bucles también pueden utilizarse en sistemas de domótica.

Imaginemos un sensor de movimiento. 

movimiento = True

while True:

    if movimiento:
        print("Movimiento detectado")
        print("Encender lámpara")
    else:
        print("Sin movimiento")
        print("Apagar lámpara")

En una instalación real, el sensor cambiaría continuamente entre diferentes estados.

El programa estaría revisándolo constantemente.

🔢 8. El bucle for

No siempre queremos repetir algo indefinidamente.

A veces sabemos exactamente cuántas veces queremos repetir una acción.

Para eso podemos utilizar for. 

for i in range(5):
    print("Motor funcionando")

Este programa repite la instrucción 5 veces.

Podemos utilizarlo, por ejemplo, para realizar una secuencia de movimientos. 

for i in range(4):
    print("Avanzar")
    print("Detener")

El robot realizará esa secuencia cuatro veces.

🤖 9. ¿Cuándo usar while y cuándo usar for?

``` ```
Bucle ¿Cuándo utilizarlo?
while Cuando queremos que el sistema continúe trabajando mientras una condición se cumpla.
for Cuando sabemos cuántas veces queremos repetir una acción.

Por ejemplo:

  • 🤖 Robot revisando sensores continuamente → while
    • ```
  • 🔄 Repetir una secuencia 10 veces → for
  • 🌱 Revisar constantemente la temperatura → while
  • ⚙️ Mover un mecanismo 5 veces → for
    • ```

🚀 11. Reto: el robot explorador

Imagina que tu robot de cuatro ruedas está explorando un terreno.

Queremos que repita esta secuencia:

  1. Avanzar.
  2. Revisar el sensor.
  3. Tomar una decisión.
  4. Continuar.

Crea un programa utilizando un bucle while y un if.

El objetivo es construir la estructura: 

while condición:

    leer sensor

    if condición:
        detener
    else:
        avanzar

💡 Todavía no necesitas conectar motores ni sensores reales. Primero estamos construyendo la lógica del robot.

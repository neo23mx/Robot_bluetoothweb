🤖 Lección 5: ¡El robot aprende a manejar muchos datos!

Listas en Python para robótica y automatización

🚀 Un robot necesita recordar información

Hasta ahora hemos aprendido a guardar información en variables. 

temperatura = 28

Esto funciona perfectamente cuando solamente necesitamos guardar un dato.

Pero imagina que un sensor de temperatura realiza una medición cada cierto tiempo.

Ahora tenemos muchos datos: 

25
27
28
30
29
31

Sería muy incómodo crear una variable diferente para cada lectura.

Para eso existen las listas.

Una lista nos permite guardar muchos datos relacionados dentro de una sola variable.

📦 1. Nuestra primera lista

Una lista se escribe utilizando corchetes: 

temperaturas = [25, 27, 28, 30, 29, 31]

Ahora la variable temperaturas contiene seis datos.

Podemos imaginarla como una caja con varios compartimentos: 

temperaturas

[25] [27] [28] [30] [29] [31]

Cada posición contiene un dato diferente.

🎯 Una lista permite que nuestro programa trabaje con muchos datos sin crear una variable para cada uno.

🌡️ 2. Una lista de lecturas de un sensor

Imagina que un sensor de temperatura de un invernadero realiza varias mediciones. 

temperaturas = [24, 26, 28, 30, 32]

Podemos mostrar toda la lista: 

print(temperaturas)

Python mostrará: 

[24, 26, 28, 30, 32]

Ahora nuestro programa tiene un pequeño historial de las mediciones realizadas por el sensor.

🔎 3. ¿Cómo obtenemos un dato específico?

Podemos pedirle a Python un elemento determinado de la lista. 

temperaturas = [24, 26, 28, 30, 32]

print(temperaturas[0])

El resultado será: 

24

⚠️ Hay algo muy importante: Python comienza a contar las posiciones desde cero. 

Posición:       0   1   2   3   4
                ↓   ↓   ↓   ↓   ↓
Temperatura:   [24, 26, 28, 30, 32]

Por ejemplo: 

temperaturas[0]   # 24
temperaturas[2]   # 28
temperaturas[4]   # 32

➕ 4. El robot puede agregar nuevos datos

Las listas pueden crecer.

Podemos utilizar append() para agregar un nuevo dato al final. 

temperaturas = [24, 26, 28]

temperaturas.append(30)

print(temperaturas)

Ahora tendremos: 

[24, 26, 28, 30]

Esto resulta muy útil cuando un sensor realiza nuevas mediciones.

Por ejemplo: 

temperaturas = []

temperaturas.append(25)
temperaturas.append(27)
temperaturas.append(29)
temperaturas.append(31)

print(temperaturas)

El programa fue construyendo la lista poco a poco.

🤖 5. Una lista de movimientos del robot

Las listas no solamente sirven para números. También podemos guardar texto.

Imagina que queremos guardar una secuencia de movimientos para nuestro robot de cuatro ruedas. 

movimientos = [
    "avanzar",
    "avanzar",
    "girar",
    "avanzar",
    "detener"
]

Ahora el robot tiene una pequeña secuencia de instrucciones.

Podemos consultar una de ellas: 

print(movimientos[2])

El resultado será: 

girar

🎯 Esto nos permite comenzar a pensar en algo muy importante: un robot puede trabajar con una secuencia de acciones.

⚙️ 6. Una lista de velocidades

También podemos guardar diferentes velocidades para los motores. 

velocidades = [30, 50, 70, 100]

Podemos interpretar estos valores como porcentajes de velocidad. 

30  → velocidad baja
50  → velocidad media
70  → velocidad alta
100 → velocidad máxima

Por ejemplo: 

print(velocidades[1])

El resultado será: 

50

🔄 7. El robot puede recorrer toda la lista

Aquí vamos a combinar algo que ya aprendimos en la lección anterior: el bucle for.

Supongamos que tenemos: 

temperaturas = [24, 26, 28, 30, 32]

Podemos recorrer todos los valores: 

for temperatura in temperaturas:
    print(temperatura)

Python irá tomando cada dato de la lista: 

24
26
28
30
32

💡 Aquí estamos combinando dos conceptos:

Lista = muchos datos

for = recorrer esos datos

🧠 8. El robot puede analizar cada lectura

Ahora vamos a combinar listas con lo que aprendimos en la lección 3: los condicionales. 

temperaturas = [24, 26, 31, 35, 28]

for temperatura in temperaturas:

    if temperatura > 30:
        print("Temperatura alta")

    else:
        print("Temperatura normal")

El programa revisa cada medición de la lista.

Podemos pensar en el proceso así: 

LISTA DE DATOS
      ↓
     FOR
      ↓
¿La temperatura es alta?
      ↓
   IF / ELSE
      ↓
    ACCIÓN

🚀 Ahora Python ya no solamente recibe un dato. Puede analizar muchos datos uno después de otro.

🌱 9. Aplicación: un invernadero inteligente

Imagina que nuestro sistema registra la humedad del suelo durante diferentes momentos del día. 

humedad = [45, 42, 38, 35, 30]

Podemos revisar cada lectura: 

for valor in humedad:

    if valor < 40:
        print("Suelo seco")
        print("Encender bomba")

    else:
        print("Humedad adecuada")

Esto representa una parte de un sistema de automatización real:

Sensor → guardar datos → analizar datos → decidir → activar actuador

Más adelante podremos sustituir estos datos de ejemplo por lecturas reales de sensores.

🏠 10. Aplicación: domótica

Las listas también pueden utilizarse para controlar diferentes dispositivos de una casa. 

dispositivos = [
    "lampara",
    "ventilador",
    "puerta",
    "alarma"
]

Podemos recorrer la lista: 

for dispositivo in dispositivos:
    print(dispositivo)

Esto nos permite imaginar sistemas donde Python administra diferentes dispositivos automáticamente.

lista

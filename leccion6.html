🤖 Lección 6: ¡El robot aprende nuevas instrucciones!

Funciones en Python para robótica y automatización

🚀 ¿Por qué necesitamos funciones?

Hasta ahora nuestro programa puede guardar información, calcular, tomar decisiones, repetir instrucciones y trabajar con listas.

Pero imagina que tenemos un robot de cuatro ruedas.

El robot necesita realizar muchas veces acciones como:

  • Avanzar.
  • Detenerse.
  • Retroceder.
  • Girar.
  • Leer un sensor.
  • Encender un actuador.

Sería muy incómodo escribir todas las instrucciones del motor cada vez que queremos avanzar.

Python nos permite crear nuestras propias instrucciones utilizando funciones.

🎯 Una función es un conjunto de instrucciones que podemos guardar y utilizar cada vez que lo necesitemos.

🧩 1. Nuestra primera función

Una función se crea utilizando la palabra def. 

def avanzar():
    print("El robot está avanzando")

Acabamos de crear una función llamada avanzar.

Pero todavía no hemos ejecutado sus instrucciones.

Para utilizarla escribimos: 

avanzar()

Python ejecutará: 

El robot está avanzando

🎯 Hemos creado nuestra primera instrucción personalizada.

🤖 2. Crear varias instrucciones para el robot

Podemos crear diferentes funciones para controlar nuestro robot. 

def avanzar():
    print("Avanzar")

def detener():
    print("Detener")

def retroceder():
    print("Retroceder")

def girar_derecha():
    print("Girar a la derecha")

Ahora podemos utilizarlas cuando queramos. 

avanzar()
avanzar()
girar_derecha()
avanzar()
detener()

Nuestro programa comienza a parecerse a un programa real de control de robots.

En este momento las funciones solamente muestran mensajes. Más adelante esos mismos nombres podrán controlar motores reales.

⚙️ 3. Las funciones evitan repetir código

Imagina que queremos encender una bomba de agua.

Sin una función podríamos escribir: 

print("Encender bomba")
print("Encender bomba")
print("Encender bomba")

Pero podemos crear una función: 

def encender_bomba():
    print("Encender bomba")

Y utilizarla todas las veces que sea necesario: 

encender_bomba()
encender_bomba()
encender_bomba()

El programa es más fácil de leer y de modificar.

📦 4. Las funciones pueden recibir información

Una función también puede recibir datos.

Por ejemplo, podemos crear una función que reciba una velocidad. 

def avanzar(velocidad):
    print("Avanzando a", velocidad, "%")

Ahora podemos utilizar diferentes velocidades: 

avanzar(30)
avanzar(50)
avanzar(80)

El resultado será: 

Avanzando a 30 %
Avanzando a 50 %
Avanzando a 80 %

El valor que enviamos a la función se llama argumento.

🚗 5. Controlar diferentes velocidades

Ahora podemos utilizar una función para representar diferentes velocidades del robot. 

def mover_robot(velocidad):
    
    if velocidad == 0:
        print("Robot detenido")

    else:
        print("Robot avanzando a", velocidad, "%")

Podemos probar: 

mover_robot(30)
mover_robot(60)
mover_robot(100)
mover_robot(0)

Observa que dentro de una función también podemos utilizar if.

Esto significa que podemos combinar los conocimientos de las lecciones anteriores.

🌡️ 6. Una función para analizar un sensor

Las funciones también son muy útiles para sensores.

Imagina un sensor de temperatura. 

def revisar_temperatura(temperatura):

    if temperatura > 30:
        print("Temperatura alta")
        print("Encender ventilación")

    else:
        print("Temperatura normal")

Ahora podemos utilizar la función con diferentes lecturas: 

revisar_temperatura(25)
revisar_temperatura(32)
revisar_temperatura(28)

La misma función puede analizar todos esos valores.

🎯 Esto es muy importante en automatización: una función puede convertirse en una herramienta para analizar sensores.

🌱 7. Una función para controlar el riego

Ahora vamos a crear una función para nuestro invernadero. 

def revisar_humedad(humedad):

    if humedad < 40:
        print("Suelo seco")
        print("Encender bomba")

    else:
        print("Humedad adecuada")
        print("Apagar bomba")

Podemos probarla: 

revisar_humedad(50)
revisar_humedad(35)
revisar_humedad(42)

Ahora tenemos una función que representa una pequeña parte de un sistema de riego automático.

🔄 8. Funciones y listas

Podemos combinar lo aprendido en la lección anterior con las funciones. 

def revisar_temperatura(temperatura):

    if temperatura > 30:
        print(temperatura, "→ ALTA")

    else:
        print(temperatura, "→ NORMAL")


temperaturas = [25, 28, 31, 33, 27]

for temperatura in temperaturas:
    revisar_temperatura(temperatura)

Observa todo lo que está ocurriendo: 

LISTA
  ↓
FOR
  ↓
FUNCIÓN
  ↓
IF
  ↓
DECISIÓN

🚀 Nuestro programa ya está empezando a tener la estructura de un sistema de automatización.

🤖 9. Crear un pequeño programa para el robot

Ahora podemos crear varias funciones para representar el comportamiento de nuestro robot. 

def avanzar():
    print("🤖 AVANZAR")


def detener():
    print("🛑 DETENER")


def girar_derecha():
    print("↪️ GIRAR DERECHA")


def girar_izquierda():
    print("↩️ GIRAR IZQUIERDA")

Después podemos construir una secuencia: 

avanzar()
avanzar()
girar_derecha()
avanzar()
girar_izquierda()
detener()

En un robot real, estas funciones podrían contener las instrucciones necesarias para controlar los motores.

Por ahora estamos aprendiendo la estructura del programa.

🔙 10. Las funciones también pueden devolver información

Una función no solamente puede realizar una acción. También puede devolver un resultado.

Para eso utilizamos return. 

def sumar(a, b):
    resultado = a + b
    return resultado

Podemos utilizar la función: 

total = sumar(20, 30)

print(total)

Resultado: 

50

En robótica esto será muy útil cuando una función tenga que leer o calcular información y entregársela a otra parte del programa.

📡 11. Una función que devuelve una lectura

Imaginemos que tenemos una función que representa la lectura de un sensor. 

def leer_temperatura():
    temperatura = 28
    return temperatura

Podemos guardar el resultado: 

temperatura_actual = leer_temperatura()

print(temperatura_actual)

Resultado: 

28

En un sistema real, en lugar de colocar el número 28, la función podría obtener el valor directamente desde un sensor.

🧠 12. La gran idea de las funciones

Ahora podemos imaginar nuestro sistema de automatización dividido en pequeñas tareas. 

leer_sensor()
        ↓
analizar_dato()
        ↓
tomar_decision()
        ↓
activar_motor()

Cada función puede encargarse de una tarea específica.

Esto hace que los programas grandes sean mucho más fáciles de entender, modificar y mantener.

🎯 Una función convierte un conjunto de instrucciones en una herramienta que podemos reutilizar.

🏆 15. Desafío de automatización

Ahora crea una función llamada: 

controlar_humedad(humedad)

La función debe:

  • Si la humedad es menor de 40 → mostrar ENCENDER BOMBA.
  • Si la humedad es igual o mayor de 40 → mostrar APAGAR BOMBA.

Después prueba: 

controlar_humedad(50)
controlar_humedad(35)
controlar_humedad(42)

🎯 Has creado una función que puede convertirse posteriormente en una parte real de un sistema de riego automático.

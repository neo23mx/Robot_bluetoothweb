🤖 Lección 7: ¡El robot aprende a organizar información!

Diccionarios en Python para robótica y automatización

🚀 Un robot necesita organizar sus datos

Hasta ahora hemos aprendido a utilizar variables, condiciones, bucles, listas y funciones.

Pero imagina que nuestro robot tiene muchos datos:

  • Nombre del robot.
  • Número de ruedas.
  • Velocidad.
  • Dirección.
  • Estado.
  • Distancia al obstáculo.

Podríamos guardar cada dato en una variable diferente, pero cuando un proyecto crece, puede resultar difícil organizar toda esa información.

Python tiene una herramienta especialmente útil para esto: los diccionarios.

🧠 1. ¿Qué es un diccionario?

Un diccionario permite guardar información utilizando una relación entre una clave y un valor.

Podemos imaginarlo como una ficha de información de nuestro robot. 

robot = {
    "nombre": "Rover",
    "ruedas": 4,
    "velocidad": 50,
    "estado": "detenido"
}

Aquí tenemos cuatro datos.

  • "nombre" → "Rover"
  • "ruedas" → 4
  • "velocidad" → 50
  • "estado" → "detenido"

La palabra que está a la izquierda es la clave. El dato que está a la derecha es el valor.

🔎 2. ¿Cómo obtenemos un dato?

Para obtener información de un diccionario utilizamos su clave. 

robot = {
    "nombre": "Rover",
    "ruedas": 4,
    "velocidad": 50,
    "estado": "detenido"
}

print(robot["velocidad"])

El resultado será: 

50

También podemos obtener el estado del robot: 

print(robot["estado"])

Resultado: 

detenido

🧩 3. Ejercicio guiado: crear la ficha de nuestro robot

Ahora vamos a construir nuestro primer diccionario paso a paso. No solamente vamos a copiar el resultado: vamos a entender cómo se construye.

🔹 Paso 1: crear el diccionario

Primero escribimos el nombre que tendrá nuestro diccionario. 

robot = {}

Las llaves { } indican que estamos creando un diccionario vacío.

🔹 Paso 2: agregar el nombre del robot

robot["nombre"] = "Rover"

Ahora el diccionario contiene una clave llamada nombre y su valor es Rover.

🔹 Paso 3: agregar el número de ruedas

robot["ruedas"] = 4

Ahora tenemos otro dato.

🔹 Paso 4: agregar la velocidad

robot["velocidad"] = 50

🔹 Paso 5: agregar el estado

robot["estado"] = "detenido"

🔹 Paso 6: revisar toda la información

print(robot)

Nuestro programa completo queda así: 

robot = {}

robot["nombre"] = "Rover"
robot["ruedas"] = 4
robot["velocidad"] = 50
robot["estado"] = "detenido"

print(robot)

🎯 Acabamos de construir paso a paso una ficha digital de nuestro robot.

⚙️ 4. Cambiar información

Una de las ventajas de los diccionarios es que podemos modificar sus valores. 

robot["estado"] = "avanzando"

También podemos cambiar la velocidad: 

robot["velocidad"] = 70

Podemos comprobar los cambios: 

print(robot)

➕ 5. Agregar información

También podemos agregar nuevas claves al diccionario. 

robot["sensor"] = "ultrasonico"

Ahora nuestro robot tiene información sobre el sensor que utiliza. 

print(robot)

🤖 6. Una ficha completa de nuestro rover

Podemos utilizar un diccionario para describir gran parte de nuestro robot de cuatro ruedas. 

robot = {
    "nombre": "Rover",
    "ruedas": 4,
    "velocidad": 60,
    "direccion": "adelante",
    "estado": "activo",
    "sensor": "ultrasonico"
}

print(robot["nombre"])
print(robot["ruedas"])
print(robot["velocidad"])
print(robot["direccion"])
print(robot["estado"])
print(robot["sensor"])

Ahora tenemos la información principal del robot organizada dentro de una sola estructura.

📡 7. Un sensor también puede ser un diccionario

Pensemos ahora en un sensor de temperatura. 

sensor = {
    "tipo": "temperatura",
    "pin": 14,
    "valor": 28,
    "unidad": "C"
}

Podemos consultar el valor: 

print(sensor["valor"])

O consultar el tipo: 

print(sensor["tipo"])

El diccionario nos permite guardar tanto el valor del sensor como información sobre el propio dispositivo.

🧩 8. Ejercicio guiado: un sensor que cambia su lectura

Ahora construiremos paso a paso un pequeño sistema que representa un sensor de temperatura.

🔹 Paso 1: crear el sensor

sensor = {
    "tipo": "temperatura",
    "valor": 28,
    "unidad": "C"
}

🔹 Paso 2: leer el valor

print(sensor["valor"])

Python mostrará: 

28

🔹 Paso 3: imaginar una nueva lectura

Supongamos que el sensor ahora detecta 34 °C. 

sensor["valor"] = 34

🔹 Paso 4: comprobar la nueva lectura

print(sensor["valor"])

Ahora Python mostrará: 

34

🎯 Observa la idea: el diccionario mantiene la información del sensor y podemos actualizar su valor cuando recibimos una nueva lectura.

🧠 9. Diccionario + if: el sensor provoca una decisión

Ahora combinaremos los diccionarios con los condicionales que aprendimos en la Lección 3. 

sensor = {
    "tipo": "temperatura",
    "valor": 34
}

if sensor["valor"] > 30:
    print("Temperatura alta")
    print("Encender ventilador")

else:
    print("Temperatura adecuada")
    print("Mantener ventilador apagado")

Python consulta el valor guardado dentro del diccionario y después toma una decisión.

Diccionario → dato del sensor → decisión → acción

🌱 10. Un sistema de invernadero

Podemos representar varios datos de un invernadero mediante un diccionario. 

invernadero = {
    "temperatura": 32,
    "humedad_suelo": 35,
    "ventilador": "apagado",
    "bomba": "apagada"
}

Podemos revisar la temperatura: 

if invernadero["temperatura"] > 30:
    invernadero["ventilador"] = "encendido"

print(invernadero["ventilador"])

Python modificó el estado del ventilador dentro del diccionario.

💧 11. Automatizando el riego

Utilicemos ahora el mismo principio para controlar una bomba. 

invernadero = {
    "humedad_suelo": 30,
    "bomba": "apagada"
}

if invernadero["humedad_suelo"] < 40:
    invernadero["bomba"] = "encendida"

else:
    invernadero["bomba"] = "apagada"

print(invernadero["bomba"])

El programa analiza la información y actualiza el estado de la bomba.

🌱 Sensor → Python → decisión → actuador

🔄 12. Recorrer un diccionario

También podemos utilizar un bucle for para recorrer la información almacenada. 

robot = {
    "nombre": "Rover",
    "ruedas": 4,
    "velocidad": 60,
    "estado": "activo"
}

for clave in robot:
    print(clave)

Python recorrerá todas las claves del diccionario.

También podemos obtener la clave y su valor: 

for clave, valor in robot.items():
    print(clave, ":", valor)

🏠 13. Diccionarios en domótica

Los diccionarios también pueden representar dispositivos de una casa inteligente. 

lampara = {
    "nombre": "Lampara sala",
    "estado": "apagada",
    "potencia": 60
}

Si un sensor detecta movimiento: 

movimiento = True

if movimiento:
    lampara["estado"] = "encendida"

print(lampara["estado"])

El diccionario ahora contiene el nuevo estado de la lámpara.

🧩 14. Ejercicio guiado: hacer que el rover decida

Ahora construiremos paso a paso una decisión para nuestro rover utilizando un sensor de distancia.

🔹 Paso 1: crear el sensor

sensor = {
    "tipo": "distancia",
    "valor": 12,
    "unidad": "cm"
}

🔹 Paso 2: comprobar la distancia

print(sensor["valor"])

El resultado será: 

12

🔹 Paso 3: crear la decisión

if sensor["valor"] < 20:
    print("DETENER ROBOT")

🔹 Paso 4: agregar una segunda posibilidad

if sensor["valor"] < 20:
    print("DETENER ROBOT")

else:
    print("AVANZAR")

🔹 Paso 5: probar otro valor

Cambia: 

"valor": 12

por: 

"valor": 50

Ahora el robot tomará una decisión diferente.

🎯 Acabamos de construir la lógica básica de un robot que utiliza información organizada dentro de un diccionario para decidir qué hacer.

🧠 15. Diccionarios + funciones

Ahora combinaremos dos conceptos que ya conocemos: diccionarios y funciones. 

def revisar_robot(robot):

    if robot["estado"] == "activo":
        print("Robot funcionando")

    else:
        print("Robot detenido")


robot = {
    "nombre": "Rover",
    "estado": "activo"
}

revisar_robot(robot)

La función recibe el diccionario del robot y utiliza su información para tomar una decisión.

🚀 16. Estamos construyendo un sistema real

Observa cómo se van conectando los conocimientos de las lecciones anteriores: 

sensor
   ↓
diccionario
   ↓
función
   ↓
decisión
   ↓
actuador

Por ejemplo: 

sensor = {
    "tipo": "distancia",
    "valor": 12
}

if sensor["valor"] < 20:
    print("Obstáculo detectado")
    print("Detener motores")

Esta es la lógica básica que posteriormente podremos conectar con sensores y motores reales.
